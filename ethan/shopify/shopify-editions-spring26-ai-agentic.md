# Shopify Editions Spring '26 - AI / Agentic / Catalog / Agent Skills

**Source:** shopify.com/editions/spring2026 (official launch page)

## 1. AEO / AI visibility (get products shown & cited)
- **Your products optimized for AI** - "Shopify gets your products in AI channels automatically. See how you're performing, track sales, and get guidance on what's missing to drive conversion."
- **Product data structured for agents** - "Shopify Catalog automatically standardizes and enriches your product data. Data syndicated by Shopify drives **2x more conversion** in AI chats."
- **Richer product data in agentic experiences** - agents show media, variants, availability, and offers from multiple sellers via Catalog API.
- **Product sourcing insights (Collective)** - visibility into empty search results, audience trends, milestones.

## 2. Agentic shopping / commerce (UCP)
- **Checkout on more surfaces** - shopping in **Copilot**, and soon **Meta ads**, powered by the **Universal Commerce Protocol**; pay directly in chat with **Shop Pay in Copilot**.
- **The open protocol for agentic commerce** - build discovery→purchase experiences with **Catalog, Cart, and Checkout MCPs** powered by UCP.
- **Ship and pick up in one checkout** - shipping + in-store pickup for different items in one checkout.
- **Demand indicators / inventory alerts** - Shop PDPs show "trending" and low-inventory flags.

## 3. Catalog / catalog mapping / product data for agents
- **Shopify Catalog** - auto standardizes & enriches product data (2x conversion claim).
- **Agentic plan** - businesses **not on Shopify** can sync products to Shopify Catalog and sell across AI channels + Shop app.
- **Sponsored products with Catalog API** - earn revenue on sales in agentic experiences (developer preview coming soon).
- **Catalog API + Shop sign-in** - shoppers connect Shop accounts; personalized search results coming soon.
- **Catalog API image search** - agents pass images to return visually similar products.
- **Catalog API product lookup** - real-time pricing/availability for up to **50 products per request** by product ID or URL.

## 4. "Commerce skills for your favorite agent" (build/manage from agents)
- **Commerce skills for your favorite agent** - "Build and manage storefronts, apps, and themes from AI tools like **Claude Code, Codex, Cursor, Hermes**, and more."
- **Store management with agents** - "Run your store inside **Claude, ChatGPT, or Perplexity**. Add products, create collections, and manage orders from the chat."
- **Shopify AI Toolkit** - manage your store from **Claude Code, Codex, Cursor, VS Code**, and more. Also: Polaris web-components upgrade + checkout-extension performance audits via the toolkit.
- **More vibe-coding partners** - spin up a store with **Manus, Replit, V0, Lovable**.
- **Shopify Dev MCP** - fewer tokens, accurate context/validation for all supported API versions.

## AEO takeaways for UpClick
- The **2x conversion** claim is Shopify's headline - useful proof point, but it's about *Shopify-syndicated data*, which still depends on the merchant populating fields correctly.
- "Commerce skills for your favorite agent" + AI Toolkit = Shopify shipping first-party agent tooling. Our edge is the **off-platform + demand-intelligence** layer Shopify can't automate.
- Catalog API **image search** validates the Image Alt-Text & Metadata offer; **sponsored products** = a future paid-placement surface (execution UI-bound today).
