# Visual Elements Gallery of Google Search

Source: https://developers.google.com/search/docs/appearance/visual-elements-gallery

An illustrated guide to the most common UI components found in Google Search results pages. Explains what each element looks like, its name, and whether website optimization is possible for each component.

## Anatomy of a Google Search Results Page

Google Search results pages contain different types of visual elements, with each search result potentially including child elements. For example, a text result can contain attribution, title links, and snippets as child elements.

The appearance of visual elements varies based on factors including device type (desktop/mobile), geographic location, search query language, and other contextual considerations.

## Main Result Types

- **Text result** - Results based on page textual content
- **Rich result** - Results typically relying on structured data markup for graphical/interactive elements
- **Image result** - Results based on embedded images, more common for image-seeking queries
- **Video result** - Results based on embedded videos, more common for video-seeking queries
- **Exploration features** - Tools helping searchers refine and expand their initial searches

## Attribution Elements

Attribution indicates a search result's source. It may include:
- **Favicon** - Small icon associated with the site
- **Site name** - Name of the website
- **Visible URL** - Readable URL format with domain and breadcrumb components
- **Domain** - Site address based on the domain name
- **Breadcrumb** - Trail showing page position within site hierarchy

## Text Results

Text results include several possible visual elements:
- **Attribution** - Source information for the webpage
- **Title link** - Clickable title linking to the webpage
- **Snippet** - Description or summary of the page content
- **Byline date** - Google's estimated publication or update date
- **Sitelinks group** - Two or more links from the same domain clustered together
- **Text result image** - Most relevant image from the webpage for the given query
- **Rich attributes** - Additional information lines powered by structured data

## Image Results

Image results display images embedded on web pages, appearing more frequently for image-seeking queries:
- **Image thumbnail** - Indexed image from the webpage
- **Attribution** - Source information for the embedding webpage

## Video Results

Video results include:
- **Video thumbnail** - Indexed video from the webpage
- **Title link** - Title linking to the video landing page
- **Attribution** - Source information for the video landing page
- **Upload date** - Publication date from video metadata

## Exploration Features

- **Related searches group** - Cluster of related searches other users have performed
- **Related questions group** - Cluster of questions related to the initial search (also known as "People Also Ask")
