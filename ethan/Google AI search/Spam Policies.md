# Spam Policies for Google Web Search

Source: https://developers.google.com/search/docs/essentials/spam-policies

Google Search's spam policies aim to protect users and improve search result quality. "Spam refers to techniques used to deceive users or manipulate our Search systems into featuring content prominently."

## Key Spam Categories

**Cloaking** involves presenting different content to users versus search engines. Examples include showing travel content to engines while displaying drug sales to users.

**Doorway abuse** creates multiple similar pages targeting specific queries to funnel users inefficiently, rather than providing direct value.

**Expired domain abuse** occurs when purchasing expired domains to host low-value content, such as "affiliate content on a site previously used by a government agency."

**Hacked content** includes code injection, page injection, content injection, and malicious redirects that compromise site security and user experience.

**Hidden text and links** deliberately obscure content from users while visible to search engines - using white text on white backgrounds or zero-opacity text, for example.

**Keyword stuffing** unnaturally fills pages with repeated keywords in lists or groups, disrupting readability.

**Link spam** involves buying/selling links, excessive link exchanges, or automated link creation schemes. Google permits qualified links (using `rel="nofollow"` or `rel="sponsored"`) for legitimate advertising.

**Scaled content abuse** generates numerous pages with minimal user value, often using AI tools or scraped/combined content from multiple sources.

**Scraping** republishes others' content without adding original value or attribution.

**Site reputation abuse** exploits an established site's ranking authority by publishing unrelated third-party content primarily to manipulate search performance.

Other violations include sneaky redirects, thin affiliations, user-generated spam, and circumvention attempts using subdomains or new sites to continue policy violations.
