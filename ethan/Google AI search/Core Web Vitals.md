# Understanding Core Web Vitals and Google search results

Source: https://developers.google.com/search/docs/appearance/core-web-vitals

Core Web Vitals represents a collection of metrics measuring real-world user experience across three dimensions: loading performance, interactivity, and visual stability. Google recommends that site owners achieve good Core Web Vitals scores to succeed in Search and provide quality user experiences. These metrics align with what Google's core ranking systems reward.

## Core Web Vitals Metrics

1. **Largest Contentful Paint (LCP)**: Measures loading performance. Target: LCP within the first 2.5 seconds of page load.

2. **Interaction To Next Paint (INP)**: Measures responsiveness. Target: INP score under 200 milliseconds.

3. **Cumulative Layout Shift (CLS)**: Measures visual stability. Target: CLS score below 0.1.

## Optimizing Your Core Web Vitals

- The Core Web Vitals report in Search Console displays page performance data
- Web.dev offers comprehensive guidance on measuring, debugging, and improving these metrics
- Multiple tools are available to measure LCP, INP, and CLS scores
