# AMP on Google Search Guidelines

Source: https://developers.google.com/search/docs/crawling-indexing/amp

Google's AMP guidelines for search results require that pages follow the "AMP HTML specification" and maintain content parity between AMP and canonical versions.

## Key Requirements

- **Valid AMP**: Pages must pass validation to qualify for search features
- **User-friendly URLs**: AMP URLs should logically relate to canonical pages (e.g., `amp.example.com/giraffes` rather than unrelated domains)
- **Content parity**: Users must access the same content and complete the same actions on AMP pages as on canonical versions
- **Structured data compliance**: Any structured data must follow Google's policies

## FAQs

**Are AMP pages mobile-only?**
No. AMP pages work across all devices when built with responsive design. AMP pages render equally well on desktop and mobile, though desktop AMP doesn't receive special search features in Google Search results.
