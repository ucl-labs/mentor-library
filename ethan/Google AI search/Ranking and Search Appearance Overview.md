# Google Search Appearance Overview

Source: https://developers.google.com/search/docs/appearance

This page documents how websites can influence their appearance in Google Search results.

## Search Appearance Features

- AI features
- Business details
- Byline dates
- Favicons
- Featured snippets
- Google Discover
- Images
- Site names
- Sitelinks
- Snippets
- Title links
- Translated results
- Videos
- Web Stories

## Structured Data

Google uses structured data to understand the content on the page and recommends providing specific information to enable richer search result features.

Google supports 30+ structured data markup types, including Article, Event, Recipe, Product, Job Posting, Local Business, FAQ, Video, and others.

## Early Adopters Program

Features include Package Tracking and Structured Data Carousels (beta).
