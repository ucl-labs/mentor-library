# Get started with Search Console

Source: https://developers.google.com/search/docs/monitor-debug/search-console-start

Search Console is a Google tool designed to help website owners understand their performance in Google Search and improve their visibility to drive more relevant traffic.

## Key Information

The tool provides insights into how Google crawls, indexes, and serves websites, enabling site owners to monitor and optimize their search performance.

Users don't need to check the tool daily - "If new issues are found by Google on your site, you'll receive an email from Search Console alerting you." However, monthly checks or reviews after content changes are recommended.

## Getting Started Steps

1. **Verify site ownership** to access all available information
2. **Ensure Google can find and read your pages** using the Index Coverage Report
3. **Consider submitting a sitemap** to potentially speed up discovery
4. **Monitor performance** through the Search Performance Report to track traffic from Google Search

## Key Reports by User Type

**For SEO specialists and marketers:**
- Manual Actions Report (identifies Google penalties)
- Removals Tool (temporarily hide pages)
- Change of Address Tool (for site migrations)
- Rich Result Status Reports (structured data issues)

**For web developers:**
- Index Coverage Report (site-wide indexing issues)
- URL Inspection Tool (page-level debugging)
- Security Issues Report (threat detection)
- Core Web Vitals Report (page experience metrics)

Pages from your site can be discovered by Google without submitting a sitemap, though doing so may accelerate the process.
