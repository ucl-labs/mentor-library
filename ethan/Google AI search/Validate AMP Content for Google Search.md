# Validate AMP Content for Google Search

Source: https://developers.google.com/search/docs/crawling-indexing/amp/validate-amp

## Overview

This Google Search Central documentation page provides guidance on validating AMP (Accelerated Mobile Pages) content to ensure proper indexing and appearance in Google Search results.

## Validation Methods

The page identifies three primary approaches for validating AMP content:

1. **AMP Test Tool** - Verifies that AMP content meets Google Search requirements
2. **Rich Results Test** - For applicable AMP types, confirms structured data parses correctly
3. **AMP Status Report** - Monitors performance across all AMP pages on a site

## Common Error Resolution

The documentation outlines four main troubleshooting steps:

1. **Ensure Discoverability** - Implement proper linking relationships using `rel="amphtml"` and `rel="canonical"` attributes
2. **Follow Guidelines** - Comply with Google Search's AMP page requirements
3. **Enable Crawler Access** - Verify robots.txt allows Googlebot crawling and remove blocking robots meta tags
4. **Validate Structured Data** - Confirm adherence to guidelines for specific page and feature types

## Additional Considerations

The page notes that indexing requires time and references external resources from ampproject.org for debugging validation and cache-related issues, including validation error documentation and cache debugging guidance.
